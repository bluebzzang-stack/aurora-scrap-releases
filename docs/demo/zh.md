# Aurora Scrap 操作演示 — 简体中文文字稿

[English](en.md) · [한국어](ko.md) · [日本語](ja.md) · [简体中文](zh.md)

本指南由Aurora Scrap开发团队编写。

此无声演示通过英语界面和画面内的英语说明介绍保存流程。它是用于说明操作流程的演示，并非经过核实的实际应用操作录屏。

[观看操作演示（MP4）](https://scrap.waple.net/guides/assets/aurora-scrap-demo-english.mp4) · [阅读资料收集指南](https://scrap.waple.net/guides/zh/)

## 分时段文字稿

1. **00:00–00:03** 从应用顶部开始新建网页收藏。
2. **00:03–00:06** 输入网页URL并确认标题。
3. **00:06–00:09** 选择分类、保存格式和截取区域。
4. **00:09–00:14** 开始保存后，新条目会出现在资料库中。
5. **00:14–00:20** 查看并放大已保存的网页截图。
6. **00:20–00:24** 在媒体选项卡中查看此演示收集到的媒体。
7. **00:24–00:27** 按媒体类型筛选列表。
8. **00:27–00:30** 打开Content (MD)选项卡，阅读已保存的文本。
9. **00:30–00:35** 也可以从Chrome扩展程序开始。
10. **00:35–00:38** 选择截取区域和保存格式，然后开始保存。
11. **00:38–00:42** 返回应用，查看已保存的资料。
