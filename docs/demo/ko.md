# Aurora Scrap 사용 흐름 데모 — 한국어 대본

[English](en.md) · [한국어](ko.md) · [日本語](ja.md) · [简体中文](zh.md)

이 안내는 Aurora Scrap 개발팀이 작성했습니다.

소리 없이 영어 화면과 영어 설명으로 저장 흐름을 소개하는 데모입니다. 사용 흐름을 설명하기 위한 영상이며, 실제 앱 세션의 화면 녹화로 검증된 자료는 아닙니다.

[사용 흐름 데모 보기 (MP4)](https://scrap.waple.net/guides/assets/aurora-scrap-demo-english.mp4) · [자료 조사 가이드 읽기](https://scrap.waple.net/guides/ko/)

## 시간별 대본

1. **00:00–00:03** 앱 상단에서 새 웹스크랩을 시작합니다.
2. **00:03–00:06** 페이지 URL을 입력하고 제목을 확인합니다.
3. **00:06–00:09** 카테고리, 저장 형식, 캡처 영역을 선택합니다.
4. **00:09–00:14** 저장을 시작하면 새 항목이 보관함에 표시됩니다.
5. **00:14–00:20** 저장한 스크린샷을 확인하고 확대해 봅니다.
6. **00:20–00:24** 미디어 탭에서 이 데모에 수집된 미디어를 확인합니다.
7. **00:24–00:27** 미디어 종류별로 목록을 필터링합니다.
8. **00:27–00:30** Content (MD) 탭에서 저장한 텍스트를 읽습니다.
9. **00:30–00:35** Chrome 확장 프로그램에서도 시작할 수 있습니다.
10. **00:35–00:38** 캡처 영역과 저장 형식을 선택한 뒤 저장을 시작합니다.
11. **00:38–00:42** 앱으로 돌아와 저장한 자료를 확인합니다.
